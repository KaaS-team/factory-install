# factory-install

This repo held the installers for KaaS Factory: `install.sh`, an npm launcher and a Homebrew template.
It is archived and no longer maintained.
The installers and the template files now live in the Go factory: https://github.com/KaaS-team/factory
Install with `curl -fsSL https://raw.githubusercontent.com/KaaS-team/factory/main/install.sh | sh` or `brew install kaas-team/tap/factory`.
[PARITY.md](PARITY.md) lists each old feature and where it went.
